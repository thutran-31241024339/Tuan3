Lab 09 – JavaScript 2: DOM and Events

Truy xuất và thay đổi cây DOM, tạo/xóa phần tử HTML, xử lý sự kiện người dùng, debug bằng DevTools và kiểm tra hợp lệ biểu mẫu (Form Validation).

Exercise 9.1

Basic DOM Selection

Truy xuất phần tử qua getElementById, getElementsByTagName, getElementsByClassName, querySelectorAll và đổi nội dung/style.

Bản hoàn chỉnh Xem #msgArea hiển thị
Exercise 9.2

DOM Family Relations

Duyệt quan hệ cha-con trong cây DOM bằng childNodes, phân biệt nodeType và tô nền xanh cho các node phần tử.

Mở bài thực hành
Exercise 9.3

Modifying the DOM

Tạo mới phần tử với createElement, createTextNode, chèn bằng appendChild và xóa phần tử bằng removeChild.

Mở bài thực hành
Exercise 9.4

Simple Event Handling

Xử lý sự kiện click (ẩn/hiện đoạn văn kèm hiệu ứng CSS và setTimeout), mouseover và mouseout trên hình ảnh.

Mở bài thực hành
Exercise 9.5

Responding to Load Events

Sử dụng sự kiện window.addEventListener("load", ...) để đảm bảo toàn bộ cây DOM đã tải xong trước khi truy xuất #div1.

Mở bài thực hành
Exercise 9.6

Debugging Events

Gắn sự kiện mouseover cho danh sách .movingDiv, sử dụng đối tượng e.target.id và đặt Breakpoint trong DevTools Sources.

Mở bài thực hành
Exercise 9.7

Working with Forms

Lắng nghe sự kiện focus và blur trên các ô nhập liệu input để tự động tô màu nền làm nổi bật trường đang nhập.

Mở bài thực hành

Form Validation
