Exercise 8.1 — Enabling/Disabling JavaScript

Hướng dẫn kiểm tra: Mặc định trình duyệt bật JavaScript sẽ hiển thị thông báo màu xanh "You have JavaScript enabled". Khi tắt JavaScript trong phần Cài đặt (Settings → Privacy and security → Site settings → JavaScript) hoặc DevTools (F12 → Ctrl+Shift+P → Disable JavaScript) rồi tải lại trang, thẻ <noscript> sẽ hiển thị "You have JavaScript disabled".
